{# Profile #}

Profile

Update your display name from the Settings page. Your name appears in compliance reports, team member listings, and email notifications. Name must be 2–100 characters.

{# Password #}

Changing your password

Under the Password section in Settings:

  1. Enter your current password
  2. Enter a new password (minimum 8 characters)
  3. Confirm the new password
  4. Click "Update Password"

You'll receive a confirmation email when the password is changed. If you didn't initiate the change, contact support immediately.

{# Notification emails #}

Notification emails

Configure up to 5 email addresses to receive compliance alerts and notifications. These addresses receive:

  • Compliance violation alerts when a label fails checks
  • Regulation change notifications (new FSSAI/AYUSH/BIS/DGFT updates)
  • License expiry reminders (30 days before expiry)
  • Label re-check alerts when regulation changes affect your products

The first email is marked as primary. Duplicates are automatically removed.

{# API keys #}

API keys

API keys allow programmatic access to RegBite's compliance checking engine. Useful for integrating compliance checks into your own systems, CI/CD pipelines, or label management software.

  • You can create up to 5 active keys
  • Keys are shown only once at creation — copy and store securely
  • Key format: rb_live_... (32 random characters)
  • Revoke any key instantly from the API Keys page
  • Revoked keys stop working immediately
{# Report branding #}

Report branding

Customise your compliance reports with your brand identity. Set a brand name (appears in the report header) and an accent colour (hex format, e.g., #2563EB) that's used for headings and highlights in PDF exports and shared report pages.
