{# Dashboard #}

Admin Dashboard

The admin dashboard shows platform-wide statistics: total users, products, compliance checks run, active subscriptions, and estimated monthly revenue. Use this for a high-level overview of platform health.

{# User management #}

User management

View all registered users with their role, plan, product count, and last activity date. From the user detail page you can:

  • View the user's products and compliance history
  • See their subscription details and billing status
  • Review their team members and invitations
{# Compliance rules #}

Compliance rules management

The rules page lists all 83 compliance rules with their code, description, severity, framework, and active status.

Syncing rules from seed

Click "Sync Rules from Seed" to load the latest rules from the seed file (app/data/fssai_rules_seed.json). This operation is additive — new rules are added, existing rules have their regulation_source updated, but no rules are deleted.

Rule versioning

Each rule tracks its version (e.g., "Version VIII"), framework (FSSAI, Legal Metrology, AYUSH, BIS, DGFT), and regulation status (Draft, Final, Effective, Superseded).

{# Regulations KB #}

Regulations Knowledge Base

The LLM Knowledge Base stores regulation documents as vector embeddings for AI-powered compliance analysis.

Seeding the KB

Click "Seed Regulations KB" to populate the knowledge base with regulation data. Seeding is additive — new documents are added without removing existing ones. The system also auto-reseeds daily when the scheduler detects new regulation changes.

Managing documents

You can view all KB documents, their chunk count, and upload custom documents. Documents are split into chunks for efficient retrieval during compliance analysis.

{# Alerts management #}

Alerts & Regulation Alerts

From the admin alerts page, you can view all system-wide compliance alerts, filter by status and severity, and publish curated Regulation Alerts that appear on all users' Reg. Alerts pages. Published alerts include a title, description, severity level, and optional source URL.

{# LLM Studio #}

LLM Studio

The LLM Studio provides a chat interface to test the AI's knowledge of regulations, view extraction quality metrics, and monitor KB health. Use it to verify that the AI correctly understands specific regulations before relying on automated compliance checks.

{# System controls #}

System & Controls

The system page shows platform configuration, database status, scheduler health, and activity logs. The activity log tracks all user actions across the platform (logins, product creation, label uploads, compliance checks, etc.) for audit purposes.

{# Daily scheduler #}

Daily scheduler

RegBite runs an in-process daily scheduler (no external dependencies like Celery/Redis):

  • 6:00 AM IST — Scrape FSSAI, AYUSH, and eGazette for new regulations
  • 6:00 AM IST — On CRITICAL changes: auto-recheck all labels, suggest rule updates via LLM
  • 6:00 AM IST — Auto-reseed LLM KB when new regulation data detected
  • 7:00 AM IST — Send license expiry reminder emails (30-day window)
