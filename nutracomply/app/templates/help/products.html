Creating a product

Products represent individual SKUs in your portfolio. Each product can have multiple label versions as your packaging evolves.

Required fields

  • Product Name — The commercial name of your product
  • Category — Determines which compliance rules apply:
    • Health Supplement — FSSAI + Legal Metrology rules
    • Ayurvedic / Siddha / Unani — Adds AYUSH-ASU rules
    • Dietary Supplement — FSSAI + Legal Metrology rules
    • Nutraceutical — Full FSSAI nutraceutical rules
    • Functional Food — FSSAI food product rules

Optional fields

  • Brand Name — Your brand / manufacturer name
  • SKU — Internal stock keeping unit code
{# Label upload #}

Uploading a label

From any product's detail page, click "Upload Label" to start a compliance check.

Supported formats

JPG, JPEG, PNG, GIF, WebP, and PDF files. For best results, use high-resolution images (300+ DPI) where all text is clearly readable.

What happens after upload

  1. The image is sent to Google Gemini Vision for AI extraction
  2. Structured data is extracted: product name, ingredients, nutrition info, claims, allergens, manufacturer details, FSSAI license number, etc.
  3. If extraction confidence is ≥ 85%, the data is cached for future re-checks (saves API tokens)
  4. The 83-rule compliance engine runs automatically
  5. You're redirected to the compliance report with your score and detailed results
{# Label versions #}

Label versions

Each upload creates a new Label Version. The most recent version is marked as "current" and determines the product's compliance score shown on the dashboard.

Previous versions are preserved for audit history. You can re-analyse any version from the product detail page to re-run compliance checks against the latest rules.

{# Bulk upload #}

Bulk upload

For large portfolios, use Products → Bulk Upload to import multiple products at once via CSV. The CSV should include columns for product name, category, brand, and SKU. Labels can then be uploaded individually per product.
