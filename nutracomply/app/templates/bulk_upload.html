How It Works

1. Upload one or more label images/PDFs

2. A product is created for each file (named from filename)

3. AI extracts label data and runs compliance checks

4. View results on each product's detail page

Tips

  • Name files descriptively — filenames become product names
  • Use clear, high-resolution label images for best extraction
  • Processing happens in the background — check products list for results
  • Duplicate product names are automatically skipped
