Changelog

What's new

Product updates, new features, and improvements to Regbite.

March 2026 v3.2
Full Website, Blog Platform & Admin CMS
  • New Public blog with categories, tags, and featured posts
  • New Admin blog editor with Quill.js WYSIWYG, SEO fields, and draft/publish workflow
  • New About, Features, Contact, Help/FAQ, Terms, Privacy, and Changelog pages
  • New Shared public base template with consistent nav and footer
  • Improved Navigation across all public pages with mobile responsive menu
March 2026 v3.1
Upgraded LLM Brains — Smarter Extraction & Compliance
  • Improved Extraction brain: dynamic confidence scoring, Gemini 2.5 Pro vision, post-extraction validation
  • Improved Compliance engine: severity-weighted scoring (CRITICAL=4x, HIGH=3x, MEDIUM=2x, LOW=1x)
  • Improved RAG brain: stopword filtering, title boosting, minimum relevance threshold
  • Fixed FORMAT checks now return LLM-assisted PASS/FAIL/WARNING instead of blanket warnings
February 2026 v3.0
Landing Page Redesign & Integrated Analyzer
  • New Fully redesigned landing page with hero compliance checker
  • New Quick Compliance Checker — instant FSSAI analysis without an account
  • New Features grid, regulation coverage section, pricing preview on landing page
  • Improved Monochrome Japanese minimal design theme with Noto Sans JP
February 2026 v2.5
Admin Controls & Permanent Data Storage
  • New Admin panel: sync rules, seed LLM KB, reseed regulations
  • New LLM Knowledge Base with additive seeding (never auto-deletes)
  • Improved All data persisted in Railway PostgreSQL permanently
  • Fixed KB type enum mismatch (uppercase REGULATIONS vs lowercase)
January 2026 v2.0
Category-Based Rule Filtering & Cached Extraction
  • New Category-based rule filtering — AYUSH rules only for Ayurvedic/ASU products
  • New Token-saving cached extraction (reuse if confidence >= 0.85)
  • New Re-analyze vs Re-extract buttons on report page
  • Fixed Health Supplements scoring 33% instead of ~80% due to AYUSH rule application
  • New Compliance rules across FSSAI, Legal Metrology & AYUSH-ASU
January 2026 v1.5
Report UI Overhaul & Legal Metrology Rules
  • New Legal Metrology Packaging rules ( MRP, net quantity, manufacturer)
  • New AYUSH-ASU rules ( ASU drug labelling, Schedule E(1), Bhasma limits)
  • Improved Compliance report UI with severity badges and remediation steps
  • Improved Admin panel cleanup and product file upload support
December 2025 v1.0
Initial Launch
  • New AI label scanning with Gemini Vision API
  • New FSSAI compliance engine
  • New User accounts, product management, label upload
  • New Compliance reports with shareable links
  • New Razorpay billing integration
  • New Team collaboration with RBAC
