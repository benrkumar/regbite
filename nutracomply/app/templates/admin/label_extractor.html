    {# Label LLM concept card #}
    Label LLM — Local Extraction Layer

    📊 How it works

    Every time an AI extraction succeeds with confidence ≥ 0.72, the field values + surrounding OCR text are stored as "patterns" in the database.

    On the next scan, these patterns are checked first (Step 1½). If a confident match is found, the AI step is skipped entirely → $0 cost.

    The more labels you scan, the smarter the local extractor becomes. Train it → it trains itself from every successful AI extraction.
