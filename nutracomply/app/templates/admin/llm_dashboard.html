{# ── How it works ──────────────────────────────────────────────────────────── #}

How it works — RAG Pipeline

📥
1. Ingest
Upload docs or auto-import from DB. Text is split into chunks.
🔍
2. Retrieve
At query time, the most relevant chunks are found via full-text search.
🤖
3. Generate
Retrieved chunks + question are sent as context to Gemini.
✅
4. Answer
Gemini replies grounded in your actual data, not general knowledge.
